## What's in the pack?

- **Farming & animals** — grow crops, raise animals and collect ingredients.
- **Cooking & food** — use the different food mods, kitchens and cooking stations.
- **Create** — build machines, farms, processing lines and other automation.
- **Building & decoration** — build homes, cafés, farms, workshops and shared towns.
- **Quests** — use Ember's Questing for pack guidance and optional goals.
- **Exploration** — find new structures, resources and places to explore.
- **Multiplayer** — build together, trade and work on shared projects.
